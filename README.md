# Donkey-Kong
Este proyecto consiste en la implementación en hardware del videojuego clásico Donkey Kong sobre una tarjeta FPGA Altera DE0 utilizando lenguaje VHDL. La arquitectura se divide de forma modular en bloques independientes que coordinan la generación de señales de sincronismo para un monitor VGA de $640 \times 480$ a 60 Hz, la decodificación de comandos mediante un teclado PS/2 y el procesamiento en tiempo real de la física y reglas de la partida. Gracias a este diseño, el sistema gestiona de manera simultánea el desplazamiento, salto y uso de escaleras por parte de Mario, la caída de barriles, la activación del martillo y los cambios de nivel con sus respectivas pantallas de estado, traduciendo toda la lógica a gráficos pixel-art directamente en pantalla sin necesidad de un microprocesador
